Bom Air Rimba

Hutan terbakar dan angin ikut mendorong apinya.

  • Api menyebar tiap detik, paling cepat ke arah angin.
  • Klik titik di peta. Pesawat terbang ke sana dan menjatuhkan bom air.
  • Petak yang terkena air padam dan kebal api sekitar 28 detik.
  • Tangki muat 3 bom dan terisi pelan. Percikan api baru muncul berkala.
  • Asap yang melewati garis batas negara di kanan bikin tetangga protes.
